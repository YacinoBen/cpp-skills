## CI/CD Quality et Static Analysis Tools
- **Clang-Format**: Enforce strict, automated code formatting rules across the repository to maintain consistent styling.
- **Clang-Tidy**: Run static analysis checks to catch modern C++ anti-patterns, potential bugs, and optimization opportunities using compilation databases (`compile_commands.json`).
- **SonarQube**: Centralize code quality metrics, vulnerability tracking, and maintainability indexes across the entire codebase.
