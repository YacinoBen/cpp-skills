# cpp-skills

**Production-grade Modern C++ reference and skill repository**, designed for high-performance systems engineering, enforcing ISO C++ Core Guidelines, memory safety, and zero-overhead abstractions.

---

## 📂 Repository Structure

The repository is organized into clean, concise, developer-oriented modules without deep nesting or redundant sub-references:

```text
cpp-skills/
├── architecture/       # Design patterns, clean code principles, and structural guidelines
├── build/              # CMake configurations, presets, and compilation standards
├── core/               # Foundational language features, lambdas, coroutines, and templates
├── hardware/           # Low-level compute, vectorization, and SIMD acceleration
├── performance/        # Memory management, container optimization, and concurrency
├── quality/            # Testing standards, diagnostics, CI/CD, and documentation
├── standards/          # Naming conventions, style guides, and coding standards
└── versions/           # Version-specific references (C++11, C++14, C++17, C++20, C++23)
```

---

## 🚀 Key Standards & Features

* **Modern C++ Focus**: Comprehensive migration and clean documentation ranging from **C++11** up to **C++23**.
* **Zero Boilerplate**: Stripped of ISO prose, raw paper references (`P...`), and external link clutter, focusing strictly on feature lists, syntax rules, and compiler compatibility tables.
* **Core Guidelines Compliance**: Strict adherence to type safety, lifetime safety, and performance best practices.
